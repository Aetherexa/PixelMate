# Marketplace Guide

## Product message
**PixelMate — Your coding companion.**

A lightweight animated companion for VS Code that reacts to your work without getting in the way.

## v1 highlights
- Smiley, Cat, Dog and Horse companions
- idle/wave/walk/celebrate/sleep reactions
- typing, diagnostics and task awareness
- low-frequency speech bubbles
- Demo, Design and Screenshot modes
- reduced-motion support
- local/offline runtime

## Listing checklist
- extension icon renders correctly
- README images use valid repository-relative paths
- commands and settings match package.json
- screenshots show normal mode without debug overlays
- privacy statement clearly states no telemetry by default
- VSIX installs cleanly in a fresh profile
