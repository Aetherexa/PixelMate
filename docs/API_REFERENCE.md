# API Reference

## Package: `@aetherexa/pixelmate-engine`

Public exports:

- Engine contracts (`PixelMateEngine`, `PixelMateEngineOptions`)
- Event contracts (`EngineEventMap`, `EventBus`)
- Plugin contracts (`PixelMatePlugin`, `PluginContext`, `PluginHost`)
- Manifest contracts
- Subsystem contracts
- Factory (`createPixelMateEngine`)
- Built-in plugin pack (`defaultBuiltInPlugins`)
- Manifest validators
- Storage adapters (`MemoryStorageAdapter`, `VSCodeMementoStorageAdapter`, `JsonFileStorageAdapter`)

Public exports:

- `VSCodeRuntimeHost`
- `RuntimeHost` interface
