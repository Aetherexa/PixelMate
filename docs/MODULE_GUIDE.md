# Module Guide

Each module publishes only interfaces through `contracts/subsystems.ts` and can be replaced by alternate adapters.

## Core

- DI composition
- Lifecycle orchestration
- Plugin registration lifecycle

## Event Bus

- Strongly typed event map
- Async listener support

## Renderer and Animation

- Scene abstraction
- Layer and sprite model
- Animation state definitions and actor playback

## Data and Runtime Services

- Settings profiles and persistence
- Storage adapter abstraction
- Statistics counters/timers
- Diagnostics and devtools reporting

## Experience Systems

- Dialogue queue with priorities and cooldown
- Missions and achievements frameworks
- Theme registration and inheritance
