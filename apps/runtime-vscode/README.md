# Runtime VS Code

VS Code Runtime Host for PixelMate.

## Public Alpha Status

This extension is currently in public alpha (`v0.1.0-alpha`).

## Features
- Activates on command pixelmate.alive
- Registers command PixelMate: Alive Check
- Shows message: PixelMate is alive!
