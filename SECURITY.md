# Security Policy

## Supported Versions
Only actively maintained minor versions receive security fixes.

## Reporting a Vulnerability
Please report vulnerabilities privately to: security@aetherexa.com

Include:
- Affected package(s)
- Reproduction steps
- Potential impact
- Suggested mitigation if known

Do not open public issues for undisclosed vulnerabilities.

## Response Targets
- Initial acknowledgement: within 3 business days
- Triage decision: within 7 business days
- Remediation timeline: based on severity
